**Имена.**
Создайте сущность Имя, которая описывается тремя параметрами: Фамилия, Личное имя, Отчество. Имя может быть приведено к строковому виду, включающему традиционное представление всех трёх параметров: Фамилия Имя Отчество (например, `Иванов Иван Иванович`).

Необходимо предусмотреть возможность того, что какой-либо из параметров может быть не задан, и в этом случае он не учитывается при приведении к текстовому виду.

`Клеопатра`\
`Пушкин Александр Сергеевич`\
`Маяковский Владимир`

Обратите внимание, что при выводе на экран не заданные параметры никак не участвуют в образовании строки.

3. Проверить, что указана хотя бы одна часть имени.
4. В методе `toString()` последовательно добавить непустые части в порядке: фамилия, имя, отчество.
5. Разделить части имени одним пробелом и вернуть полученную строку.
6. Создать и вывести имена из условия задачи.

## Задача 4
### Текст задачи
**Время.**
Создайте сущность Время, которая будет описывать текущее время в 24-часовом формате. Время описывается числом секунд, прошедшим с начала суток.

Время может быть приведено к текстовой форме следующего типа: `ЧЧ:ММ:СС`.

Например, если время задано как `12000`, то текстовая форма будет иметь вид `3:20:00`.

Если время будет превышать 24 часа, то текстовая форма должна отражать только то время, которое прошло с начала последних суток. Например, `91800` — это не `25:30:00`, а `1:30:00`.

Необходимо создать и вывести на экран текстовую форму для следующих вариантов времени:\
`10` секунд\
`10000` секунд\
`100000` секунд

### Алгоритм решения
1. Создать класс `Time` с полем для хранения количества секунд с начала суток.
2. Проверить, что исходное количество секунд неотрицательно.
3. Получить количество секунд с начала текущих суток, взяв остаток от деления исходного значения на `86400`.
4. Получить часы делением количества секунд на `3600`.
5. Получить минуты делением количества секунд на `60` и взятием остатка от деления на `60`.
6. Получить секунды взятием остатка от деления на `60`.
7. В методе `toString()` сформировать строку в формате `ЧЧ:ММ:СС`.
8. Создать объекты для значений из условия и вывести их на экран.

# Задание 2

## Задача 4
### Текст задачи
**Сотрудники и отделы.**
Создайте сущность Сотрудник, которая описывается именем в строковой форме и отделом, в котором сотрудник работает. У каждого отдела есть название и начальник, который также является Сотрудником.

Сотрудник может быть приведён к текстовой форме вида: `Имя работает в отделе Название, начальник которого Имя`.

В случае если сотрудник является руководителем отдела, текстовая форма должна быть: `Имя начальник отдела Название`.

Необходимо выполнить следующие задачи:
1. Создать сотрудников Петрова, Козлова и Сидорова, работающих в отделе `IT`.
2. Сделать Козлова начальником отдела `IT`.
3. Вывести на экран текстовое представление всех трёх сотрудников. У всех трёх должен оказаться один и тот же отдел и начальник.

### Алгоритм решения
1. Создать класс `Department` с полями для названия отдела и ссылки на начальника.
2. Создать класс `Employee` с полями для имени сотрудника и ссылки на отдел.
3. Создать один объект отдела с названием `IT`.
4. Создать Петрова, Козлова и Сидорова, передав каждому ссылку на созданный отдел.
5. Назначить Козлова начальником отдела.
6. В методе `toString()` класса `Employee` проверить, является ли сотрудник начальником отдела.
7. Если сотрудник является начальником, вернуть строку вида `Имя начальник отдела Название`.
8. Иначе вернуть строку с именем сотрудника, названием отдела и именем начальника.
9. Вывести текстовое представление всех трёх сотрудников.

# Задание 5

## Задача 4
### Текст задачи
**Сколько сейчас времени?**
Измените сущность Время из задачи 4.4. Добавьте ей возможность возвращать следующие сведения:\
Какой сейчас час — целое число.\
Сколько минут прошло с начала текущего часа — целое число.\
Сколько секунд прошло с начала текущей минуты — целое число.

Необходимо выполнить следующие задачи:
1. Вывести на экран, сколько часов соответствует времени `34056`.
2. Вывести на экран, сколько минут соответствует времени `4532`.
3. Вывести на экран, сколько секунд соответствует времени `123`.

### Алгоритм решения
1. Создать в классе `Time` метод `getHours()`, который возвращает текущий час.
2. Создать метод `getMinutes()`, который возвращает количество минут с начала текущего часа.
3. Создать метод `getSeconds()`, который возвращает количество секунд с начала текущей минуты.
4. Создать объект времени для `34056` секунд и вызвать метод `getHours()`.
5. Создать объект времени для `4532` секунд и вызвать метод `getMinutes()`.
6. Создать объект времени для `123` секунд и вызвать метод `getSeconds()`.
7. Вывести полученные результаты.

Пример 1:\
Время — `34056` секунд\
Результат — `9` часов

Пример 2:\
Время — `4532` секунды\
Результат — `15` минут

Пример 3:\
Время — `123` секунды\
Результат — `3` секунды
